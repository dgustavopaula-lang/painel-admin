🌿 Laboratório de Plantas

…

Registro para pesquisa botânica. Registrar uma planta não significa que ela é segura para consumo. Nunca consuma planta sem identificação confirmada por especialista.

Toque e escolha Câmera para fotografar agora ou Galeria/Arquivos para usar fotos já tiradas.

🥬 Horta orgânica · diário de campo

Toque num canteiro e registre o que fez: reguei, semeei, vi praga, colhi… Funciona sem internet; vai para a NexoTerraCore API quando houver rede.

➕ Novo canteiro

Dica real: canteiro com 1 m de largura (alcança o meio sem pisar), 20–30 cm de altura e caminhos de 40–50 cm.

Conexão com a NexoTerraCore API

Use uma API Key só para este app, com os escopos plantas.read e plantas.write. Ela fica guardada apenas neste aparelho.

Como funciona

1. Tire as fotos e registre, mesmo sem internet: tudo fica guardado no celular.
2. Quando a internet voltar, toque em Sincronizar: os dados vão para a API.
3. Em Plantas, toque numa planta para ver a análise comparativa (mesmo gênero, mesma família, mesma parte, usos parecidos e alertas).
As fotos ficam no celular nesta versão; o envio das fotos para a VPS vem na próxima etapa.
